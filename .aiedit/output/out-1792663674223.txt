<h3>Отчёт: таргет aether_p2p_e2e в C-клиенте</h3>
<p><b>1. Файлы таргета.</b><br>
Собираются два файла:<br>
<code>tests/p2p_e2e.c</code> — основной e2e-сценарий<br>
<code>tests/p2p_test_support.c</code> — вспомогательный код (платформа, транспорт, крипто)</p>

<p><b>2. CMakeLists.txt.</b><br>
<pre>
add_executable(aether_p2p_e2e
    tests/p2p_e2e.c
    tests/p2p_test_support.c
)

    PRIVATE aether_client aether_hydrogen_test_support
)
target_compile_features(... c_std_11 ...)
</pre></p>

<p><b>3. Использование stream в тестах C-клиента.</b><br>
В <code>tests/</code> есть упоминания <code>stream</code>, но <b>не</b> <code>csa_login_stream</code>.<br>
Примеры — <code>test_generated_local_dispatch.c</code> использует <code>safe_stream_t</code>, <code>global_stream_t</code>; <code>test_generated_stream_builder.c</code> использует <code>sb_command_stream_t</code> и <code>sb_command_stream_stream_api_*</code>.<br>
В <code>p2p_e2e.c</code> stream-методы <b>отсутствуют</b> полностью.</p>

<p><b>4. Stream-API в <code>src/generated/aether_api.h</code>.</b><br>
Экспортируются методы вида <code>csa_login_stream_authorized_api_*</code> (строки 2767–2843):
<pre>
csa_login_stream_authorized_api_back_id(...)
csa_login_stream_authorized_api_ping(...)
csa_login_stream_authorized_api_client(...)
csa_login_stream_authorized_api_send_message(...)
csa_login_stream_authorized_api_send_messages(...)
csa_login_stream_authorized_api_send_multicast(...)
csa_login_stream_authorized_api_send_message_with_result(...)
...
</pre></p>

<p><b>5. Вывод.</b><br>
Текущие C-тесты (включая <code>aether_p2p_e2e</code>) <b>не вызывают</b> <code>csa_login_stream_*</code>. Причины:<br>
— <code>csa_login_stream_authorized_api_*</code> — сгенерированный API для работы с потоком авторизованных команд (backId, ping, sendMessage и т.д.);<br>
— e2e-тест работает напрямую с базовыми примитивами <code>aether_*</code> (регистрация, обработка через <code>aether_work</code>) и проверяет peer-to-peer взаимодействие без сервера, поэтому stream-методы не используются.</p>
